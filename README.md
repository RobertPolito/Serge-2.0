# Serge-2.0 AI
Progetto di tesi: utilizzo di modelli di intelligenza artificiale per supportare il serious game SERGE 2.0 nella formazione al Risk Management.

## Contenuto
- `src/` – codice Python (train, validate, predict)
- `dataset/` – carte di rischio sintetiche
- `schemas/` – schema JSON
- `artifacts/` – modelli addestrati
- `bibliografia.bib` – fonti della tesi
